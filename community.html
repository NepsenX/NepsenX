Community FAQ

Can anyone read the discussions?

Public GitHub discussions can generally be read without signing in. To post, reply or react, GitHub may require an account.

Will my comment be stored on this website?

No. The static website does not save comments itself. Messages are posted and stored on GitHub when you submit them there.

Can I ask about NepsenX on YouTube, Facebook or X?

Yes, if you find the relevant public account. The portal links to platform search results where a specific official account URL has not yet been verified.

How do I ask Google to show a question from this page?

The page includes readable FAQ content and metadata, but search engines decide independently whether and when to index it or show a rich result. No site can guarantee FAQ rich snippets or ranking.
